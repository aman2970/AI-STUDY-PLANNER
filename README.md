# 📚 AI Study Planner

AI Study Planner is a web-based study management application designed to help students organize their subjects and manage their study activities efficiently.

## 🚀 Features

- 🔐 User Signup and Login
- 🔒 Password hashing
- 👤 User sessions
- 📚 Subject management
- ✏️ Add and update subjects
- 🗄️ SQLite database
- 📊 Student dashboard
- 🌐 Flask backend
- 📱 User-friendly web interface

## 🛠️ Tech Stack

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Python
- Flask

### Database

- SQLite

### Tools

- GitHub
